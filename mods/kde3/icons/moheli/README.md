# Moheli decoration artwork

Original: Olivier Fourdan, Xfce xfwm4, themes/moheli. GPL v2 (COPYING).
Source: https://github.com/xfce-mirror/xfwm4/tree/30eb3437bb9d410eeb17b22412c53505d26e3176/themes/moheli
Upstream commit: 30eb3437bb9d410eeb17b22412c53505d26e3176.

Unchanged original XPMs, README and themerc are in source/. SVGs reproduce their
declared pixel geometry; symbolic GTK colors are resolved using palette.json.
The accent is classic blue, inactive titles gray, with original silver controls.
Rows beyond an XPM's declared height are ignored, as in an XPM image loader.
manifest.json records original/converted hashes and dimensions. No Xfce binary or upstream code was installed or executed. Runtime uses only local static SVG assets.
